# Privacy Policy

**Marketplace to Excel Exporter**

Effective date: 2026-11-16

Marketplace to Excel Exporter is a Chrome extension that helps users extract listing details from the currently open Facebook Marketplace item page and export those details to a CSV file.

## Data We Process

The extension processes the following listing fields from the active page when the user clicks extract:

- Title
- Amount (price)
- Location
- Description
- Listing link
- Seller rating

## How Data Is Used

- Data is used only to display results in the extension popup and generate CSV exports requested by the user.
- Data is stored locally in the user's browser using `chrome.storage.local` to support cumulative CSV export behavior.

## Data Sharing and Transfer

- We do **not** sell user data.
- We do **not** transfer extracted data to external servers.
- We do **not** share extracted data with third parties.

## Permissions Used

- `activeTab`: access the user-selected active tab after interaction.
- `scripting`: read listing fields from the active Marketplace page.
- `downloads`: save CSV files requested by the user.
- `storage`: store extracted rows locally on device.

## Data Retention and Deletion

- Extracted data remains in local browser storage until the user clears extension/site data or uninstalls the extension.
- Users can also overwrite previously saved rows by extracting the same listing again.

## Security

- The extension operates locally in the browser and does not include remote data transmission features.

## Children's Privacy

- This extension is not directed to children under 13.
